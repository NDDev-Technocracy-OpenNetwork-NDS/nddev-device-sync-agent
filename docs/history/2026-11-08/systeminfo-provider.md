# Canonical Systeminfo provider

The standalone Systeminfo repository moved to
`NDDev-Technocracy-OpenNetwork/nddev-systeminfo`. The shared acceptance downloader
now accepts that canonical OpenNetwork organization alongside the historical
organization still used by existing provider locks. Size, digest, extraction
and attestation requirements are unchanged. The sysinfo adapter owns its
separate release pin and real-provider acceptance.
