# nddev-device-sync-agent working contract

Public AGPL-3.0-only NDDev OpenNetwork module. Never commit private device inventory,
paths, endpoints, credentials or runtime evidence. Keep domain/application OS-neutral,
native I/O in adapters, tasks and payloads bounded. Existing tools own their state. No
arbitrary remote shell, backup/recovery or protected RDS changes. Run `just check` and
the affected real-provider acceptance before review.
